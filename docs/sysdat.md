# sysdat (subroutine)

The subroutine `SYSDAT` controls the I/O of all system dependent parameters as well as the parameters `NTERM`, `LAMMIN`, `LAMMAX`, and `MPROJ`.

Currently the Hibridon package contains `SYSDAT` subroutines for different collision systems described in more detail on the [Basis subroutines](basis) page.
