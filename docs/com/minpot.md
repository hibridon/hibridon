# MINPOT

The command `MINPOT` invokes a simple search procedure to find the minimum in the isotropic potential where [`XMU`]../XMU.md) is the collision reduced mass in atomic units. Thus, to estimate the turning point of $V(R)$ alone, without any centrifugal barrier, set [`JTOT1`]../param/jtot.md) = 0 before entering the command [`TURN`](./turn.md).
