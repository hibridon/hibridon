# J1J2

`J1J2` is an array (up to 50 elements) allowing the user to set specific values for j1-j2 in case of collisions involving 2 molecules.

Specific j1-j2 values are set with the following syntax:

```
J1J2,<numj>,<j1j2(1)>,...,<j1j2(numj>)
```

Each element encodes a couple $(j_1, j_2)$ in the form: $10\ j_1 + j_2$.

note:
- terminate the string with a semicolon if other parameters will follow on the same line, e.g.:

```
J1J2,2,00,10;energ=e1,e2,e3;JTOT1=0,JTOT2=2....
```
