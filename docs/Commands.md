A number of commands are available to direct the operation of the Hibridon code:

- [`DEBROGLI`](DEBROGLI): Calculate and print out the DeBroglie wavelength for the system defined by the current [parameters](Parameters)
- [`DIFCRS`](DIFCRS): Calculate a differential cross section using previously computed S matrices
- [`DIFFER`](DIFFER): Compares two previously computed S matrices
- [`EADIAB`](EADIAB): Determine locally adiabatic energies using previously calculated transformation matrices
- [`FLUX`](FLUX): Determine quantum fluxes for photodissociation or collisions
- [`INTCRS`](INTCRS): Calculate integral cross sections using previously computed S matrices
- [`MACHDAT`](MACHDAT): Display on the screen and in the main [output](Output) file the important details of your current hardware
- [`MINPOT`](MINPOT): Estimate minimum in the isotropic part of potential
- [`MRCRS`](MRCRS): Determine m-state resolved integral cross sections using previously determined tensor cross sections
- [`OPTIMIZE`](OPTIMIZE): Optimize system independent [parameters](Parameters)
- [`PARTC`](PARTC): Print out a subset of previously calculated partial cross sections
- [`PRINTC`](PRINTC): Print out a subset of previously calculated integral cross sections
- [`PRINTS`](PRINTS): Print out previously calculated S matrices
- [`PSI`](PSI): Determine the expansion coefficients of selected channel components of the scattering wavefunction
- [`READ`](READ): Read in [parameters](Parameters) and [flags](Flags) from the currently defined [input](Input) file
- [`OPTIMIZE`](OPTIMIZE): Optimize one (or more) [parameters](Parameters)
- [`RUN`](RUN): Start a scattering calculation using the current [parameters](Parameters) and [flags](Flags)
- [`QUIT`](QUIT): Terminate the currently running scattering program
- [`SAVE`](SAVE): Save the current [parameters](Parameters) and [flags](Flags)
- [`SHOW`](SHOW): Display on the screen and in the main [output](Output) file the current [parameters](Parameters) and [flags](Flags)
- [`TENXSC`](TENXSC): Calculate tensor cross sections using previously computed S matrices
- [`TESTPOT`](TESTPOT): Print out value of the potential and/or the expansion coefficients of the potential at a given value of R
- [`TURN`](TURN): Estimate classical turning point from isotropic part of potential
