A number of commands are available to direct the operation of the Hibridon code:

- [`CHECK`](./com/check.md): 
- [`DEBROGLI`](./com/debrogli.md): Calculate and print out the DeBroglie wavelength for the system defined by the current [parameters](Parameters)
- [`DIFCRS`](./com/difcrs.md): Calculate a differential cross section using previously computed S matrices
- [`DIFFER`](./com/differ.md): Compares two previously computed S matrices
- [`EADIAB`](./com/eadiab.md): Determine locally adiabatic energies using previously calculated transformation matrices
- [`FLUX`](./com/flux.md): Determine quantum fluxes for photodissociation or collisions
- [`INTCRS`](./com/intcrs.md): Calculate integral cross sections using previously computed S matrices
- [`MACHDAT`](./com/machdat.md): Display on the screen and in the main [output](./com/out.md) file the important details of your current hardware
- [`MINPOT`](./com/minpot.md): Estimate minimum in the isotropic part of potential
- [`MRCRS`](./com/mrcrs.md): Determine m-state resolved integral cross sections using previously determined tensor cross sections
- [`PARTC`](./com/partc.md): Print out a subset of previously calculated partial cross sections
- [`POT`](./com/pot.md): Allows the user to use another potential datafile
- [`PRINTC`](./com/printc.md): Print out a subset of previously calculated integral cross sections
- [`PRINTS`](./com/prints.md): Print out previously calculated S matrices
- [`PRSBR`](./com/prsbr.md): Calculate pressure-broadening cross sections
- [`PSI`](./com/psi.md): Determine the expansion coefficients of selected channel components of the scattering wavefunction
- [`READ`](./com/read.md): Read in [parameters](Parameters) and [flags](Flags) from the currently defined [input](./com/input.md) file
- [`OPTIMIZE`](./com/optimize.md): Optimize one (or more) system independent [parameters](Parameters)
- [`RUN`](./com/run.md): Start a scattering calculation using the current [parameters](Parameters) and [flags](Flags)
- [`QUIT`](./com/quit.md): Terminate the currently running scattering program
- [`SAVE`](./com/save.md): Save the current [parameters](Parameters) and [flags](Flags)
- [`SHOW`](./com/show.md): Display on the screen and in the main [output](./com/out.md) file the current [parameters](Parameters) and [flags](Flags)
- [`TENXSC`](./com/tenxsc.md): Calculate tensor cross sections using previously computed S matrices
- [`TESTPOT`](./com/testpot.md): Print out value of the potential and/or the expansion coefficients of the potential at a given value of R
- [`TURN`](./com/turn.md): Estimate classical turning point from isotropic part of potential
